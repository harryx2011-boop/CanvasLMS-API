| Symptom | Likely cause | Fix |
|---|---|---|
| `401 Unauthorized` | Token is wrong or revoked | Generate a new token and update `CANVAS_TOKEN` |
| `404 domain not found` | Wrong host | `CANVAS_URL` should be your school's Canvas address |
| Redirected, `302`, or an HTML login page | `CANVAS_URL` points at the wrong host or path | Check the URL matches what you use to log into Canvas in a browser |
| `403` on grading or roster tools | Student token | Expected. These tools need an educator account |
| Server not listed in `/mcp` | Servers load at session start | Restart Claude Code |
| `python -m venv` fails with a permissions error on Windows | Standard venv tooling can hit permission issues | Use `uv venv .venv` instead |
| No enrolled course matches | Wrong identifier or course not visible to the token | Run `list_courses` and use the id from its output |
| `429` or rate limit | Too many concurrent requests | Wait a minute, then lower `CANVAS_MAX_CONCURRENCY` |

Run `canvaslms-api --test` any time. It checks the connection and prints an actionable hint for the common failures above.
